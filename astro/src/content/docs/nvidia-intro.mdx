**Latest update:** 12-jan-2026

As most newer cards will work with the latest drivers, older cards are no longer supported by the latest drivers. Nvidia is sorting out older GPU to legacy branch this cards are not supported by the latest driver.

[nvidia-open](https://archlinux.org/packages/extra/x86_64/nvidia-open/): open source NVIDIA kernel modules package best for all cards up from 16xx

The first thing you should do is get knowledge about your card and supported driver:

##### NVIDIA Turing GPU, GTX 16xx RTX 20xx and newer.

These are supported by the main nvidia packages [nvidia](https://archlinux.org/packages/extra/x86_64/nvidia-open/)[-](https://archlinux.org/packages/extra/x86_64/nvidia-open/)[open](https://archlinux.org/packages/extra/x86_64/nvidia-open/), [nvidia-open-lts](https://archlinux.org/packages/extra/x86_64/nvidia-open-lts#/) and [nvidia-open-dkms](https://archlinux.org/packages/extra/x86_64/nvidia-open-dkms/)

You always need at minimum `nvidia-open` and `nvidia-utils` packages installed, in addition you may need lib32 support packages for Gaming on Steam or Wine: [lib32-nvidia-utils](https://archlinux.org/packages/multilib/x86_64/lib32-nvidia-utils/) per example.

If these packages do not work, [nvidia-beta](https://aur.archlinux.org/packages/nvidia-beta/)AUR may have a newer driver version that offers support.

For older Legacy Devices, read here: [about-legacy-gpu](https://www.nvidia.com/en-us/drivers/unix/legacy-gpu/) on Nvidia Website.

You will need the related [nvidia-580xx-utils](https://aur.archlinux.org/packages/nvidia-580xx-utils) [AUR] (example branch) package installed in addition to got the driver working.

##### You can also use our tool to check your card:

`nvidia-inst --test`

This will show info about your GPU, related installed packages, and gives the commands to install Nvidia packages, but will not actually change anything itself, usefull in case you have no clue to show someone helping you.

If you have PC with a dedicated card plugged in you can use nvidia-inst to get latest driver installed, for more info go here:

[nvidia-inst](/new-nvidia-driver-installer-nvidia-inst/)

With the introduction of the [eos-hwtool](https://github.com/endeavouros-team/PKGBUILDS/tree/master/eos-hwtool#readme) you can easily get drivers installed with one simple command:

`eos-hwtool --no32 --install-recommended`

If you do plan to install steam best is to install 32 bit libs too: `eos-hwtool --install-recommended`

**📖 Notes:**

* **No RTD3 power management on Turing 
Crashes on some laptops:** The proprietary NVIDIA Linux driver supports **RTD3 runtime power management** only in specific configurations and treats it as *experimental* on Turing GPUs. Documentation notes *initial experimental support* for Turing notebook GPUs, and real-world reports show that RTD3 is often disabled by default or leads to instability (e.g., ‘Runtime D3 status: Not supported’ or system hangs/crashes) on some laptops. For details, see the official NVIDIA README on dynamic power management and user reports on Arch and Fedora forums.
